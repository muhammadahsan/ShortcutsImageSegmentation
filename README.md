## Investigating Spurious Cue Sensitivity in Semantic Segmentation
The code for the work "Investigating Spurious Cue Sensitivity in Semantic Segmentation". Our paper has been accepted as an Oral at ANNPR 2026 (Artificial Neural Networks in Pattern Recognition - 2026). [Find the full paper here ](./https://github.com/muhammadahsan/ShortcutsImageSegmentation/blob/main/ShortcutsImageSegmentation.pdf.pdf). I hope this will help you to reproduce the results. 
## Environment
Please prepare an environment with python=3.7, and then use the command "pip install -r requirements.txt" for the dependencies.
